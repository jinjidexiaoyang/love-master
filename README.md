## 这是什么

市面上大多数"AI 恋爱助手"在做一件事：**截一张图，要一句回复**。

恋爱大师做的是另一件事：围绕**一个具体的人**，建立一整份可以持续追踪的关系档案——聊天记录、阶段演进、风格样本、导师知识全部放进同一个引擎。它不替你聊天，它让你**先看清局面，再说对话**。

核心原则只有一条，写进了每一行代码：

```
判断是导师级的，表达永远是你自己的。
```

## 为什么它不一样

### 🧠 联系人级长期记忆
不是孤立的截图问答。每个联系人都有独立的档案：关系阶段演进、每日节奏、好感度与暧昧度趋势、性格画像——AI 的每一次判断，都建立在这段关系的**全部历史**之上，而不是一条消息。

### 🎭 你的风格 DNA
系统内置一套风格引擎：从你自己的聊天样本中蒸馏出属于你的表达基因。AI 给出判断和策略，但最终说出口的话，**必须像你**——不是像 ChatGPT，不是像情感博主。

### 🧙 四位化名导师 · 3,500+ 实战知识卡
内置四位导师（观局者 / 灰狼 / 调情师 / 破象者）共 **3,531 张**脱敏实战知识卡，支持三种问答模式：全部导师综合研判、指定导师深挖、**多导师同题对比**——让四个流派给你的同一个局面出不同处方。

### ⚔️ 判断与表达严格分离
优先级链写死在架构里：`你的 DNA > 联系人上下文 > 当前对话 > 模型自由发挥`。防止 AI 退化成讨好型、咨询师型、模板型——这是所有同类产品最容易翻车的地方。

## 功能总览

| 页面 | 能力 |
|---|---|
| 📊 总览 | 全局 KPI：高热度 / 降温中 / 暧昧中，逐联系人阶段卡片墙 |
| 👤 联系人 | 关系阶段进度、每日消息节奏、好感度·暧昧度双轴趋势、性格画像、互动统计（消息占比 / 24h 活跃时段 / 高频词） |
| 💬 聊天分析 | 三种格式自动识别入库 · 局面分析 · 回复建议 · 开场白 · 策略中心（推拉 / 框架 / 废测应对…） |
| 🧠 导师问答 | 3,531 张知识卡本地检索 · 综合研判 / 指定深挖 / 多导师对比 |
| ⚙ 设置 | 界面内直接配置 Anthropic / DeepSeek 的 Key，保存即生效，一键测试连通 |
| 🛠 管理后台 | 独立后台：导入你自己的导师素材、批量建卡、风格核心蒸馏 |

> 说明：好感度 / 暧昧度等数值为 AI 模型估计，供决策参考，非精确测量。

## 快速开始

```bash
# 1. 安装（Python 3.10+）
pip install -r requirements.txt

# 2. 启动
streamlit run app.py

# 3. 在「⚙ 设置」页填入 API Key（支持 Anthropic / DeepSeek），保存即可用
```

也支持 `.env` 方式配置（优先级更高）：复制 `.env.example` 为 `.env` 填入即可。

> 🔒 你的 API Key 只保存在本机（`data/api_config.json`，已列入 .gitignore），不上传、不入库。

## 已知边界（如实说明）

- 单用户本地应用，无云端同步与移动端

- 不含任何微信自动读取能力（合规红线，永不添加）；聊天请使用粘贴导入
